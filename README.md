
  # Wine Cellar Management Website

  This is a code bundle for Wine Cellar Management Website. The original project is available at https://www.figma.com/design/lB4PMOs6qKEsbOvcvKSly5/Wine-Cellar-Management-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  
  Run `python -m uvicorn reading_wines.main:app --reload` to launch the world map
